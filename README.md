# Prototipos ILMI (web)

Copias publicadas de los prototipos HTML de ILMI para que el equipo los vea con un enlace:
**https://icaria-atelier.github.io/ilmi-prototipos/**

- **Este repositorio es público.** Solo contiene las copias publicadas (HTML e imágenes). Las páginas llevan «no indexar», pero cualquiera con el enlace puede verlas.
- El fuente de cada prototipo vive en el repo privado `ILMI_Design`, en la carpeta de su pieza. No se edita aquí: se copia con el script `publicar-web.sh` de la skill `prototipo-ilmi`.
- Nunca se publica aquí la fuente Ilmi ni material marcado como confidencial.
